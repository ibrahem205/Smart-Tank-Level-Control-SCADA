# Smart-Tank-Level-Control-SCADA

Siemens TIA Portal | Factory I/O | Ignition | OPC/OPC UA

Project description

This project was developed as part of the Learning SCADA course.

The original course project was modified to create a water tank level control system. The original timer-based control was replaced with a PID-based control approach, allowing the tank level to be controlled according to a desired setpoint.

The project also involved working with analog signals and PLC objects to convert raw analog input into a readable tank-level value for the SCADA system.
